# 设计和UI

界面、视觉系统、品牌 design.md 相关 skill。

## Skills

| 目录 | 用途 | 来源 |
| --- | --- | --- |
| `design-md/` | 把品牌判断写成 design.md，约束 CSS primitives | 本仓库 |
| `holo-card/` | 从图片生成可交互全息卡 | [LerSent001/holo-card](https://github.com/LerSent001/holo-card) |
| `answer-me-with-html/` | 复杂解释做成一页可视化 HTML | [QingYunA/answer-me-with-html](https://github.com/QingYunA/answer-me-with-html) |
| `archify/` | 想法或代码库画成可交互架构 / 流程 / 时序 / 数据流 / 生命周期图 | [tt-a1i/archify](https://github.com/tt-a1i/archify) |
| `jakubkrehel-skills/` | 界面设计工程技能集合（UI 打磨、字体、颜色、无障碍、布局、文案 + review / 状态机 / 变体工作流） | [jakubkrehel/skills](https://github.com/jakubkrehel/skills) |
| `anatomy/` | 一句话生成精细可交互等距机械图（物体即解释；SVG + WebGL / 3D） | [wheresryan22/anatomy](https://github.com/wheresryan22/anatomy) |
| `brands-design-md/` | 品牌 DESIGN.md / tokens 参考库（无 SKILL.md） | [ricocc/brands-design-md](https://github.com/ricocc/brands-design-md) |
| `fantastic-posters/` | 用 GPT Image 2 生成 31 种风格海报，自动选风格、构建提示词并出图 | [robonuggets/fantastic-posters](https://github.com/robonuggets/fantastic-posters) |

## 安装

```bash
cp -R 设计和UI/design-md ~/.grok/skills/design-md
cp -R 设计和UI/holo-card ~/.grok/skills/holo-card
cp -R 设计和UI/answer-me-with-html ~/.grok/skills/answer-me-with-html
cp -R 设计和UI/archify ~/.grok/skills/archify
cp -R 设计和UI/jakubkrehel-skills ~/.grok/skills/jakubkrehel-skills
cp -R 设计和UI/anatomy ~/.grok/skills/anatomy
cp -R 设计和UI/fantastic-posters ~/.grok/skills/fantastic-posters
```
