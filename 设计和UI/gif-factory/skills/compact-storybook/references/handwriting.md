# 正文书写效果

已认可三页试样：总18秒、实际6fps；每次页面落稳或正文切换后延迟1/6秒，两行正文约0.9秒写完，标题与页码保持静态。快速书写与低声沙沙声配合，写完即停，保留原阅读和动作时长。起步值可按文案长度调整，不能为了效果挤掉阅读时间。

## 文字

- 保留用户认可字体、字色、字号、位置、行距与分行。字体不是笔顺数据，不能把字体轮廓描边冒充笔迹。
- 用逐字、逐笔画路径逐渐显露最终字体的alpha，不用整行水平擦除、打字机逐字蹦出或整组淡入替代书写。
- 可将汉字标准笔顺中线映射到实际字体的墨迹包围框，再用有宽度的路径作揭示蒙版；要说明这属于近似，不声称还原了字体真实书写轨迹。没有对应数据的标点可短暂显现；缺字与正文汉字不得静默略过。
- 把字形及几何缓存，使用时间确定揭示进度。最终完成状态必须恢复完整原字形，不能因蒙版太窄留下残笔。换字体需重新匹配笔迹与检查。
- 每组正文都建立独立开始时间；一页多组对白时按各组节拍重新写。每个开始时间与对应书写声共同从一份时间表派生。
- 翻页期间新页正文保持空白；落页后才写。旧页已经写好的正文随旧页翻走，不倒写、不在翻页中重复开写。

## 沙沙声

沿用已认可书写素材，剪成与写入同长的短声。用户要求无声时取消；不能加旁白、笔点击或持续底噪。声音明显低于配乐，轻起轻止，保留原配乐的连续性；写完至下一次落笔之间必须安静。

已认可案例：0.9秒短声，约20ms淡入、50ms淡出；素材峰值约-20.9dBFS，含间隔整轨平均约-44.3dBFS，仅供该素材复现。更换音源要重新量测，不能机械套增益数值。样例素材来源 https://sfxmint.com/sounds/pencil-writing-01 ，源站标注CC0及AI生成，不称为实录。标准汉字笔顺样例来自 https://github.com/skishore/makemeahanzi ，使用和分发按实际所用数据许可处理，不将字库、数据和音效许可混为一谈。

音效可保留为独立stem，再与配乐混音，便于调音量。多段trim/delay输出后先量测：文件有音轨不代表有声音；已遇到非空WAV但全轨静音的情况。检查实际非零样本、电平、各cue开始结束、总时长和成片混音峰值。没有人工试听就不声称听感通过。

## 检查

每种版式抽看落页前、落页后未写、写入中、全部写完四种状态；多组对白另看切换。确认最终完整文字与原版一致、无残笔、无截字。实际6fps仅约5–6帧完成写入，要用户确认这个节奏，不静默提高帧率。获认可后再扩展完整故事，并复核所有正文cue和声音间隔。
