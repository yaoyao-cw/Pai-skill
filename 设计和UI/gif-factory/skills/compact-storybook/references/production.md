# 制作与检查

## 状态连续性

每页记录：页号、背景、角色、起始状态、主要动作、结束状态、道具持有者/数量、下一页如何承接。

例如：一张蓝灰纸由熊递给女孩 → 折成纸鸟 → 放飞 → 狐狸接住 → 展开读信。这是一个道具的形态变化，不能落手时又多一只鸟。狐狸把叶子交给熊后，下一页不能仍持有同一片叶子。

跨页可切换环境和构图，用同一对象、动作结果或视线衔接；不补大量走路过场假装连续，不擅自换成远景/特写/反打镜头组。

## 姿态图组合

- 背景不含本次叠加的角色和动态道具，防止残影、重复物件。
- 单个动作可起步绘制8–12个关键姿态，分配到约18个输出帧；姿态数和停留由动作决定，不必等时。
- 固定画布、镜位、比例和画格布局；逐格检查错脸、变衣服、多手、道具突变。缺格不能跳过关键接触动作。
- 对全部姿态使用公共alpha裁切范围、统一缩放和稳定脚底基线。不要每帧单独紧裁后填满画格，否则人物忽大忽小、脚底漂移。只有像素风用最近邻缩放，插画保留抗锯齿。
- 全部资源解码后再注册可跳转的确定性时间线，每帧由时间计算，不靠实时计时、未固定随机数或网络返回顺序。

## 接触与遮挡

持有物使用每个姿态的手心锚点；静置物使用桌面/地面锚点。飞行终点接到落手锚点，接住后随手移动，不能继续按独立路径漂走。

区分椅子/后景、身体、手及持有物、桌面前沿。直接重画整条背景会裁断手和杯子，需逐个姿态检查。放下时，从持有层切换到静置层，只出现一次。

实测问题：纸鸟最后落在手下方；杯子沿用胸口坐标，放下后悬空。修实际锚点和遮挡，不把上次坐标硬套给新角色。

## 紧凑节奏

3秒页起步：约0.2–0.4秒建立姿态，约1.5–2秒完成动作，约0.5–1秒看清结果。复杂动作可适当延长或拆成两页，不强塞3秒。

N页、每页d秒、翻页p秒：总长 `N*d+(N-1)*p`。已认可案例12×3+11×0.5=41.5秒，四章各三页=每章10秒，仅为案例规格。

6fps的0.5秒翻页只有3帧，要检查能否辨认纸页翻动。书框不应盖住动作。用户要独立动画就不加书框；不能把外层升到30fps后仍称整个文件6fps。

## 验收与分享

在工程目录运行当前渲染器检查。一个根入口，其他入口放子目录，避免多根入口冲突；具体命令以当前帮助和技能为准，不照搬旧版本。

检查实际解码首中末帧、交接前后、翻页前中后和手机尺寸文字。Canvas可能被静态检查误判静止，用实际帧变化核实后才记录为误报。

无声只是上次样片状态，不是所有故事的硬要求。按用户需求和授权处理声音，缺音乐时可先交付动作版并注明无声，不静默承诺配乐已完成。

记录规格、检查结果和未确认的美术质量。检查通过不代表用户满意。分享工程前去掉私人路径、原图和未使用素材；不打包无分发权的字体，换许可字体或提供替换说明。
