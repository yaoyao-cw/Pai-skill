# 动态艺术签名

保留准确名字、意象、配色和最新认可稿。字稿、动画、交付版式分开处理，只改速度时不换字。延续旧款先实际打开[案例](references/examples.md)，新稿使用可用的图像生成工具。

支持多种字体，也可以自定义。用户可以选书体、描述笔画感觉，或提供字体参考、字体文件和现成字稿；名字、意象、乐器、配色与动效按需求调整。先看[多字体示例与自定义方法](references/multifont.md)，样例用于比较效果，不限制新的字体方向。

## 先把字写出特点

按[设计说明](references/design.md)，让物体进入笔画、轮廓或字内留白，不能只是旁边放图标。保持名字可读，用平面手写墨迹、提按粗细和尖收笔；不默认加金属、立体、发光或粉笔质感。

上方意象和下方名字、长尾是两个独立书写组，靠近处留小空隙。相连时先修稿或明确分层遮罩，不能把连在一起的成品用横向擦除切成两半。某例把眼睛藏进字母的做法不是所有名字都要照搬。

中文默认草书，用户指定行书、瘦金体等书体就按要求；看[中文字与两三字布局](references/chinese.md)。换书体时保留签名构图、意象、配色和两段书写节奏，三字不等于必须写三段，也不自动改成逐笔教学演示。

用户要乐器入字或字意粒子时，看[乐器案例与分层方法](references/instrument-semantic.md)：琴弦、管身、音孔等共用目标字的笔画，粒子按字意运动，落到目标笔画后凝成字。普通款不自动加粒子。

## 字变了，做法跟着变

新字稿、换书体或用户提供字稿时，读[字体适配](references/font-adaptation.md)。先看当前稿的粗细、牵丝、连笔、独立点画和回转方向，再重新分层与规划动画。保留字形的个性，不为了方便动画改成模板字，也不按字体名字套固定坐标。

这些工作由代理完成，用户不需要填写组件编号、遮罩或起笔坐标。先由脚本按实际墨迹计算起点、路径、笔头宽度和碎片大小，再看预览；粘连、分叉或语义归属不对时，代理修当前稿的分层或路径后重算。用户已指定的书体、字稿、配色、节奏和效果优先，自动参数不覆盖明确选择。

## 再做书写节奏

默认不透明深灰底、960×640、4 秒循环，MP4 60fps、GIF 25fps。明确要求可改。

| 阶段 | 默认节奏 |
| --- | --- |
| 干净空白 | 0.30 秒 |
| 上方一笔 | 0.14 秒，果断加速 |
| 停顿 | 上方写完后 1.02 秒 |
| 下方开始 | 第 1.46 秒 |
| 主体快写 | 约 0.16–0.18 秒 |
| 末锋慢收 | 再用约 0.65–0.72 秒，逐渐减速 |
| 完成与循环 | 保留完整稿，最后 0.30 秒只淡出墨迹 |

上方一笔也必须沿墨迹逐段写出，不能整层淡入。未写到的地方必须干净，不能垫一张暗淡的完整字稿。普通款默认无抖动、回弹、光效和声音。尾部转向就沿实际曲线走，不能用从左到右的擦除冒充往回写。表中是默认节奏；字体变化优先调整路径、分层和运动幅度，只有拥挤到看不清或用户另有要求时才调整时长。

## 工具与检查

看[渲染配置](references/rendering.md)。新稿默认用 `render_ink_signature.py`；需要 Python 3、Pillow、NumPy，导出再用 FFmpeg，检查视频用 ffprobe。它根据当前分层适配墨迹方向和粗细，不恢复书法家的精确笔顺。

```bash
python3 scripts/render_ink_signature.py --config assets/adaptive/Woyunjian/write.json --out /tmp/signature --plan-only
python3 scripts/render_ink_signature.py --config assets/adaptive/Woyunjian/write.json --out /tmp/signature
python3 scripts/audit_video.py /tmp/signature.mp4
```

每张图重新检查分层和阈值，不盲用旧稿编号、路径或碎片参数。主体与长尾的遮罩要互斥，整条尾巴留给末锋阶段，避免出现两遍或接缝。`--plan-only` 输出六张实际中间帧和自动计算记录；先看顶部是否逐段写出、停顿时下方是否干净、主笔到末锋的交接，再导出正常播放检查。旧 `render_signature.py`、`render_semantic_signature.py` 保留用于重跑各自旧例，不拿旧例坐标适配新字体。

未来笔画提前出现就去掉底层完整稿；上下串笔先修连接处；机械描字就加快主体，把减速留给末锋。检查实际中间帧和正常播放，静态封面不能算完成动画，技术检查不能代替视觉判断。

## 交付

交付 MP4 和循环 GIF，封面只作补充。九宫格要有九个不同的名字、意象或配色方案，用九个实际成片运行 `scripts/make_grid.py`，不能交静态拼图。需要时加合集 ZIP、配置和可复现素材，私人参考截图不放进公开包。

作为 GIF 工厂的一部分时保留总入口和其他用途，不用签名模块覆盖整个仓库。
