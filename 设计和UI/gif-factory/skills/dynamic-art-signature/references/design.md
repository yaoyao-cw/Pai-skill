# Signature design guidance

## Inputs

Resolve exact text, object and gradient. Interpret short prompts such as `Levi + 乌鸦 + 白黑渐变` as a visual design brief. If the user says “自己设计”, choose a cohesive original set instead of asking for all inputs again.

## Composition

Choose a clear principal pen gesture and a readable connected word. Fuse object traits into ascenders, counters, crossbars, terminals or swashes: wing-like rising letters, a crescent upper loop, leaf-shaped negative space. A complete literal animal pasted onto a finished word is not integration. Avoid forcing all motifs onto the same letter or formula.

Preserve broad-nib pressure changes, hairline joins and decisive taper. Clean ink can feel handwritten without scratches. Keep text exact, sufficient margins and strong contrast. Dark background and palette are defaults only. Avoid copying the reference's exact topology, logos, watermark, phone UI or designer credits.

For the accepted two-gesture look, plan exclusive upper and lower ink before generating. A connected component can contain several small flourishes, but one frame must never accidentally reveal a neighboring group's ink. If a solid dark-background raster is used, keep the background uniform and free of shadows to enable clean keying. Prefer genuine RGBA layers when available; black accents need real alpha rather than dark-background luma segmentation.

## Prompt skeleton

Create an original custom handwritten signature with exact text [NAME], motif [OBJECT] integrated into the letter anatomy and negative space, and flat matte [GRADIENT] ink. Use expressive natural pen pressure, readable connected letters and a tailored silhouette. Plan two physically separated gesture groups with small intentional gaps: [UPPER LETTER GESTURE], [LOWER WORD AND TERMINAL]. Use a clean flat charcoal background or true transparency. Keep 10–14% horizontal margins. No extra text or watermarks; no metal, bevels, shadows, glow, chalk or realistic pasted-on object.

Add a design-specific idea; do not repeat this skeleton without adapting letter structure. Generate with the image tool, inspect the result, and make targeted visual corrections with the image tool. Use scripts for animation, compositing and delivery, not as a substitute for requested original artwork.
