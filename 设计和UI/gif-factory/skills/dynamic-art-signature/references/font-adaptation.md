# 让字体决定怎么动

用户说换字体、用这张字稿、再做一个名字时，代理负责把字和动画配起来。先沿用最新认可的稿和选择；没有指定书体时，根据名字、意象和现有系列选合适的手写结构，不要求用户先选分类或填参数。

支持多种字体和自定义字形，见[九种字体方向](multifont.md)。用户给现成字稿时按要求保留；只给字体参考或字体文件时，先做出对应名字的可审阅字稿，再设计意象融合和分层。只给风格描述也能开始，不把某组案例当成固定字库。

## 先看图，再选办法

| 当前字形 | 处理办法 |
| --- | --- |
| 细直线、牵丝、尖钩多 | 保留长线和尖锋，减小运动与扭转；要墨迹聚合时切成较长的笔画碎片，避免变成一堆小圆点 |
| 粗笔、提按明显 | 保留有厚薄变化的墨块；笔头覆盖当前笔宽，转角跟笔画走，不用同一条细线描所有字 |
| 草书、英文连笔和回环 | 按连笔的走势分组；回转处沿曲线显现，检查交叉口有没有同时涌出几条支线 |
| 行楷、独立点画、分开的部件 | 逐个确认归属，抬笔处不补连接线；仍按整体快写节奏，不自动改成逐笔教学 |
| 乐器入字、字意粒子 | 只把已选目标笔画交给效果层；保住琴弦、音孔、管身等辨识细节，其余字按正常书写处理 |

表格用于选择办法，不是五种字体模板。同一个名字换稿，也要重新看粗细、连通情况和末锋方向。字形可以有不规则的提按、偏心和独特转折；只修错字、串笔、裁切和影响辨识的问题。

## 代理做分层，脚本算初稿

先打开原图。用当前图的连通区域、真实透明度和必要的局部遮罩，整理为互斥的 `upper`（顶部意象）、`first`（正常快写字身）、可选 `rest`（墨迹聚合目标）及 `tail`（整条慢收锋）。遮罩由代理制作，不让用户填写路径或编号。缺少慢收锋时可省略 `tail`，不要硬加一条长尾。

分层只分已有墨迹，不重画字。透明图使用真实 alpha；不透明图按墨迹与底色的差别取边，检查细灰线、点画、乐器结构和抗锯齿边缘。上下粘连或互相遮挡时，代理根据图义修分层；真要改字稿时才使用图像工具，保留用户明确要求沿用的稿。

给 `render_ink_signature.py` 的基础配置只要原图、分层、底色和效果选择。起笔点、尾巴路径、碎片大小可以不填。脚本会：

- 从当前墨迹估计笔宽，沿墨迹连通方向计算展开位置；顶部默认在 0.14 秒里加速写出。
- 从字身靠近末锋的位置起笔，沿整条末锋减速走完；分离点画之间只安排抬笔时间，不在空白里画线。
- 普通款使用 `write`，不加粒子。明确选择 `ink-fragments` 时，按笔宽和画布尺寸计算碎片大小、位移和扭转，落定后还原原有颜色与笔画。
- 保留配置中已明确填写的参数。旧图的坐标不是新图的默认值。

## 看到问题就修当前稿

先跑 `--plan-only` 看六张实际中间帧，再导出视频看正常播放。自动计算只是起点，不等于视觉检查通过。

顶部起笔方向别扭，代理根据当前笔势填 `upper_pen.start_point`；复杂回环同时冒出支线，就拆开对应笔势或补当前稿的路径；尾巴从末端倒写，就校正 `tail_pen.start_point` 或 `tail_path`。不要改成整层淡入、横向擦除或最后补一张完整图。

细线断了先修分层和取边，不先加粗字体；乐器细节糊成噪点就减少碎片、位移和旋转；某段看不清再调整那一段的时长。用户只要求换书体时，尽量保留已经认可的停顿和总节奏。

静态图片无法可靠恢复真实书写笔顺，特别是交叉、覆盖和飞白处。需要精确逐笔时，代理另做笔画图层；当前适配生成的是符合当前字形的视觉笔势，交付时不宣称恢复了真实笔顺。
