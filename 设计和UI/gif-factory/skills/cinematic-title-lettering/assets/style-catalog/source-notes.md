# 图片说明

F01–F10 是早期试作，F11–F20 是选定的十款原版，F21–F40 是后来新增的二十款。继续用旧稿时按编号找原图。

这些是 AI 生成的设计图。前十张用了实拍照片作参考，[照片来源在这里](../film-title-examples/source-credits.md)；后面三十张参考了用户提供的片头设计，片名和场景重新设计。参考原图没有放进仓库。

想直接使用这版，就下载对应的 PNG。想沿着同一方向再做，可以查看[原版十款提示词](selected-prompts.json)和[新增二十款提示词](new-prompts.json)。重新生成的结果会有差别。

重排总览可用[总览脚本](../../scripts/render_style_catalog.py)，它只拼排已有图片。
