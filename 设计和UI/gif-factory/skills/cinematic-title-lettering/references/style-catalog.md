# 40 种电影片名字的风格

先看图，挑喜欢的编号，再说片名和想要的感觉。每张都是按那句话重新写的，换片名时也会重新设计。

场景图、片名文案或现成字稿都可以自己提供。可以只设计字、只配场景，也可以把你给的图片和字稿排成一张片头图。

> 例：用 F25 空心双线，做一张《晚风借我一夜》的片头，场景也帮我配。

## 怎么用

字可以歪一点、挤一点、有些停顿，但要认得出来。场景、颜色和英文跟着片名一起设计，细节从笔画里长出来。

有喜欢的旧图就直接指定编号；想试几个方向，也可以给同一句话做对照。字的风格和[五种排法](layout-recipes.md)可以搭配着选。
