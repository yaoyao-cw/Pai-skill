# 黏土角色 × 拼贴机关：15 秒试片

1920×1080 / 30fps / 15s。沿用已接受的三位原创黏土店员；参考 gbro-collage-broll 的视觉命题、空场组装、少物件和首尾态设计。此版使用可编辑分层合成，未调用 Gemini 视频生成。

0–5s：可颂伸手抓纸条、后仰拉动；同一店铺切成三折依次展开，字随后落位。动作先于结果。
5–10s：纸烤箱卡位、炉门翻开，无盘面包沿弧线落到手托的唯一盘子；承重下沉；面包上扬、托盘退出。
10–15s：面包落入品牌外带袋；吐司与咖啡从袋口露头，可颂在袋旁迎客。大标题和袋身店名至少稳定约3秒。

统一奶油白/鼠尾草绿/陶土红。主体3–6组，不以整体淡入/慢zoom代替组装。只对各组做确定性的位移、纸面折叠和遮挡。角色16姿态，共享裁切与缩放。每个道具同一时间只有一个归属；面包层不带盘子。保留真实纸袋前后遮挡。
