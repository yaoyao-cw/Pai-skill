## 关键决定

1. **三次图像操作保持不变，另加一个验收步骤。** 3.1 的基础生成、温和修正、强化修正均保留；最后一张只标为 `final-candidate`。新验收步骤不调用图像模型。
2. **合同升级为 `family-crayon-card-v4`。** 这是验收语义变化，不能继续沿用 v3 让旧调用端误认兼容。所有配方代码块、两段修正 prompt 和锚点像素不变；历史 v3 记录保持原文。
3. **不制造统一审美分数。** 3.1 按自己的识别点逐项检查，不能套用 20 号色板阈值；也不能将“记录齐全”写成“脚本独立看懂了图”。
4. **视觉审核通过不等于用户认可。** 审核记录标明 human／agent 及证据。用户认可只能来自真实用户反馈；不为每张图默认新增用户确认环节。
5. **先补选型依据，不做推荐模型。** 新增独立 `--catalog` 查询，现有 `--list` 输出结构和显式指定画风的行为不变。未指定画风且需求足够时给 2–3 项候选及理由；用户仍决定。
6. **第一期不生成、不编辑、不上传图片。** 复用文本证据和现有展示入口，不将隐私清理失败的研发图重新包装成公开展示图。
