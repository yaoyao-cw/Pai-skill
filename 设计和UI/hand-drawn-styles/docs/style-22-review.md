## 使用

```bash
python3 -B scripts/render_prompt.py --style vermilion-ink-wash \
  --subject '原图人物扶着自行车，保留眼镜、长发、姿态与车架连接' \
  --source-image /absolute/path/source.jpg --text '只保留球衣上的10'
```

JSON 包依次给出画风锚点、可选内容原图和其他角色参考，以及完整预处理说明。调用端先执行预处理，再把真实图片按角色顺序传给图像工具；得到 JSON 不等于图像模型已经使用锚点。只提供文本时可创作新内容，不强制复制骑行构图。
