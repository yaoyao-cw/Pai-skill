# Skills工具

管理、打磨、安装 agent skill 的工具型 skill。

## Skills

| 目录 | 用途 | 来源 |
| --- | --- | --- |
| `luban/` | 鲁班：把 Skill 打磨成可传播的公共资产 | [LearnPrompt/luban-skill](https://github.com/LearnPrompt/luban-skill) |
| `kitter/` | Kitter CLI：可复用 skill 库的添加/安装/生效集 | [what1f/kitter](https://github.com/what1f/kitter) |

## 安装

```bash
cp -R Skills工具/luban ~/.grok/skills/luban
cp -R Skills工具/kitter ~/.grok/skills/kitter
```
