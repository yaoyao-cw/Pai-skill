# 淘宝抢购 / 下单

淘宝没有连接器。用已登录的 Chrome 在商品页操作。目标是真正生成订单，不是“看着像点了”。

## Resource Guide

| 资源 | 何时用 |
|---|---|
| `scripts/taobao-snipe.js` | 开售前注入到商品页 console，作整点备份（只点「立即购买」/「提交订单」） |
| `scripts/extension/` | 可选：加载 Chrome 扩展，自动注入同一套逻辑 |
| `examples/drop-run.md` | 限时开售演练提示词 |

脚本点不了 `isTrusted` 点击。选 SKU 和开售整点点「立即购买」必须以桌面真实鼠标为主路径；脚本只是备份。

## 先问清再动手

必须有：商品链接、目标 SKU 原文、数量、可接受价格区间。没有规格就不要点购买。

限时开售还要有：开售时刻（默认当天 12:00 Asia/Shanghai）、开售前几分钟开页。

运行时改 `scripts/taobao-snipe.js` 顶部 `CONFIG`：

- `itemId` — 商品 id
- `skuMatch` — SKU 匹配正则源串（例 `v1\\.2`）
- `forbiddenSku` — 永不买的规格子串（例 `防拍`）
- `minPrice` / `maxPrice` — 可接受价
- `dropHour` / `dropMinute` — 开售时刻（上海时区）
- `qty` — 数量，默认 1

## 硬规则

- 只开 **一个** 商品标签。多标签会卡死浏览器。
- 选规格必须用桌面 **真实鼠标**。JS/DOM 合成点击经常选不中，会弹「请选择您要的商品信息」。
- 点「立即购买」，不要点「加入购物车」（开售前按钮经常还是购物车）。
- 价格离谱（例如 ≥10000 占位价）= 未开售或已售罄，不要下单。
- 禁止买用户排除的规格（常见：防拍、灰色无货项）。
- 开售时刻 **之前** 不要点「立即购买」。
- 开售当天上午不要改抢购 routine（改日程会弹批准卡，卡住开抢）。
- 下单若被 Auto-review 拦住：立刻用同一动作提起批准卡，不要干等、不要改 routine。

## 限时开售怎么抢

1. 开售前 5–10 分钟：只开一个标签打开商品页，关掉翻译弹窗，确认已登录。
2. 用真实鼠标点选目标 SKU，确认选中、价格在区间内。停在这一页。
3. 注入备份脚本：商品页 DevTools console 粘贴 `scripts/taobao-snipe.js` 全文并回车；或预先加载 `scripts/extension`。脚本在开售前只倒计时，不点购买。
4. 开售整点：真实鼠标点「立即购买」。若弹「请选择您要的商品信息」，马上再真实点一次 SKU，再点立即购买。
5. 确认订单页点「提交订单」（必要时先勾选支付币种）。
6. 抢到或售罄立刻用中文告诉用户。抢到了立刻让他用手机淘宝/支付宝付待付款。

唤醒略晚于开售时刻仍立刻尝试，不要因超时放弃。

## 验证码

考拉 / 滑块 / 拼图：不要连点。先截图，用视觉 + 真实鼠标拖到对齐。大约 10 秒过不了，把电脑交给用户，同时告诉他。

## 付款

支付宝安全校验、扫码、密码：不要替用户付。立刻告诉用户用手机淘宝/支付宝付待付款；需要扫电脑上的码就把电脑交给他。

## 普通现货（不是限时抢）

同样：一个标签、真实鼠标选 SKU、立即购买、提交订单、付款交给用户。跳过倒计时即可。可不注入脚本。

## 质量标准

- 成功 = 订单已生成（待付款即可），或明确售罄/目标 SKU 变灰。
- 失败 = 只点了看起来像点了、点了购物车、下了占位价、买了排除规格。
