# 六种个人 IP 风格模板

这是一份可以直接在 GitHub 中打开的风格选择页。先根据使用场景选择一个主风格编码，再把编码连同照片和用途交给 `$personal-ip-image-pack`。

[返回项目首页](README.md) · [查看机器可读的完整风格规范](references/style-specs.yaml)

## 快速选择

| 你的主要需求 | 优先考虑 |
| --- | --- |
| 头像、聊天反应、轻量表情包 | `IP-01` 简笔涂鸦头像 |
| 干净、现代、适合个人品牌的头像或封面 | `IP-02` 清透扁平肖像 |
| 高饱和、有手绘颗粒、视觉辨识度强 | `IP-03` 粉蜡笔撞色肖像 |
| 完整人物、穿搭变化、生活动作 | `IP-04` 彩铅换装小人 |
| 内容叙事、日常场景、连续小剧场 | `IP-05` 治愈手帐小剧场 |
| 强轮廓、强撞色、适合海报和封面 | `IP-06` 粗线撞色漫画 |

## `IP-01` · 简笔涂鸦头像

**视觉感觉**：圆形大头、极简五官、粗而柔软的黑色手绘线、粉色腮红和一个低饱和点缀色。信息少，但表情直接、缩小后仍容易辨认。

**适合生成**：头像、肩像、半身表情贴纸。

**不支持生成**：完整全身、换装、场景卡。

**默认原型**：1:1 头像，白底或透明背景。其他资产规格以 [`asset-forms.yaml`](references/asset-forms.yaml) 为准。

复制使用：

```text
使用 $personal-ip-image-pack。我选择 IP-01 简笔涂鸦头像，主要用于头像和聊天表情。请先根据我的授权照片建立人物原型，在我确认之前不要批量扩展。
```

## `IP-02` · 清透扁平肖像

**视觉感觉**：几乎没有描边，以干净的大色块和两级以内的平面明暗塑造人物；头部放大、五官简化，整体清透、现代。

**适合生成**：头像、半身贴纸、个人品牌封面卡。

**条件支持**：全身人物需要先确认能否保持角色一致性。

**不支持生成**：换装。

**默认原型**：1:1 头像，品牌纯色或浅蓝绿色背景。其他资产规格以 [`asset-forms.yaml`](references/asset-forms.yaml) 为准。

复制使用：

```text
使用 $personal-ip-image-pack。我选择 IP-02 清透扁平肖像，主要用于个人品牌头像和封面。请先建立并让我确认人物原型。
```

## `IP-03` · 粉蜡笔撞色肖像

**视觉感觉**：头部占比较大，以厚重、不透明的粉蜡笔或油画棒色块直接塑形；颗粒、断裂和涂抹感明显，配色大胆。

**适合生成**：头像、半身表情贴纸、全身人物和动作贴纸。

**不支持生成**：换装。

**默认原型**：1:1 头像，白底配少量同色系手绘符号。其他资产规格以 [`asset-forms.yaml`](references/asset-forms.yaml) 为准。

复制使用：

```text
使用 $personal-ip-image-pack。我选择 IP-03 粉蜡笔撞色肖像，希望人物有强烈手绘颗粒和高饱和撞色。请先建立并让我确认人物原型。
```

## `IP-04` · 彩铅换装小人

**视觉感觉**：约 2.5–3.5 头身的完整 Q 版人物，服装、袜子、鞋子和配饰清楚；使用柔灰色彩铅轮廓、纸张颗粒和低饱和糖果色。

**适合生成**：全身立绘、全身贴纸、换装、生活动作和头像裁切。

**不支持生成**：场景卡。

**默认原型**：4:5 全身人物，透明或干净纯色背景。其他资产规格以 [`asset-forms.yaml`](references/asset-forms.yaml) 为准。

复制使用：

```text
使用 $personal-ip-image-pack。我选择 IP-04 彩铅换装小人，主要需要完整人物、生活动作和换装资产。请先建立一张全身原型让我确认。
```

## `IP-05` · 治愈手帐小剧场

**视觉感觉**：极简点状五官、淡腮红、松弛细线和克制自然色。人物与一个必要的微型场景元素共同表达清楚的小故事，并保留大量留白。

**适合生成**：单人贴纸、微场景卡、连续日常场景。

**不支持生成**：换装。

**默认原型**：4:5 场景卡，使用简洁背景。其他资产规格以 [`asset-forms.yaml`](references/asset-forms.yaml) 为准。

复制使用：

```text
使用 $personal-ip-image-pack。我选择 IP-05 治愈手帐小剧场，希望围绕我的内容主题制作有留白的日常微场景。请先建立人物与基础场景原型让我确认。
```

## `IP-06` · 粗线撞色漫画

**视觉感觉**：极粗且统一的黑色轮廓、图形化漫画五官、强烈深色发型块面和两到三种高饱和主色，缩略图状态下依然醒目。

**适合生成**：头像、半身贴纸、海报和封面卡。

**条件支持**：全身人物需要先确认能否保持角色一致性。

**不支持生成**：换装和场景卡。

**默认原型**：1:1 头像，高饱和纯色背景。其他资产规格以 [`asset-forms.yaml`](references/asset-forms.yaml) 为准。

复制使用：

```text
使用 $personal-ip-image-pack。我选择 IP-06 粗线撞色漫画，主要用于醒目的账号头像和内容封面。请先建立并让我确认人物原型。
```

## 还没有想好选哪种？

先告诉 Codex 你最常用的渠道、希望交付的资产类型，以及想传达的气质。例如：

```text
使用 $personal-ip-image-pack。我还没有确定风格。我的主要渠道是小红书，希望制作头像、6 个常用表情和 3 个工作动作；整体感觉要亲切、专业、容易在小尺寸下辨认。请先推荐 2 个最匹配的风格，并说明取舍。
```

## 交互式 HTML 版本

仓库内还保留了带参考图和复制按钮的[交互式 HTML 风格库](assets/style-library/index.html)。GitHub 出于安全原因只展示 HTML 源码，不会直接运行页面。

如需使用交互功能，请先[下载整个仓库](https://github.com/DoraRabbitYan/personal-ip-image-pack/archive/refs/heads/main.zip)，解压后在浏览器中打开：

```text
assets/style-library/index.html
```

其中的内置参考图仍受[素材权利台账](references/style-asset-rights.yaml)约束。当前六组图片均为 `pending_clearance`，只能用于本地风格研究，不能传入图像生成工具，也不能当作可复用素材再次分发。
