# Pai Infinite Loop IP

Design original anime character IPs for brand Pai. Motif is ♾️ — infinite loop, each cycle different, never stopping. Do not copy earlier candidates. Do not chase photo likeness unless the user asks.

## Quality lock (first traveler)

Match this production bar, not later ornate or stiff variants.

- Japanese light manga, thin crisp lineart, flat cel-shading
- Cream seamless studio background
- Standing full body, readable silhouette, simple pose, contact shadow only
- Three-color costume plus cream
- One small floating familiar that encodes the loop
- Modest rendering, not gacha splash, not painterly, not dark
- No text, no watermark
