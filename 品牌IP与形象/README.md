# 品牌IP与形象

本会话用到的 IP / 头像 / 角色设计 skill。分类与 `设计和UI`、`购物` 并列。

## Skills

| 目录 | 用途 | 来源 |
| --- | --- | --- |
| `ip-as-logo/` | 极简圆角吉祥物方图，三色、从边角探出 | [s1dashu/ip-as-logo-skill](https://github.com/s1dashu/ip-as-logo-skill) MIT |
| `personal-ip-image-pack/` | 授权照片转可复用个人卡通 IP | [DoraRabbitYan/personal-ip-image-pack](https://github.com/DoraRabbitYan/personal-ip-image-pack) |
| `ip-character-designer/` | 动漫 IP 全案，S3 日系轻漫画等 10 种画风 | [Beatatata/ip-character-designer](https://github.com/Beatatata/ip-character-designer) MIT |
| `pai-infinite-loop-ip/` | Pai 品牌专用：无限循环 ♾️、永不相同、奶油底全身人设 | 本会话沉淀 |

## 安装

```bash
cp -R 品牌IP与形象/ip-as-logo ~/.grok/skills/ip-as-logo

cp -R 品牌IP与形象/ip-character-designer ~/.grok/skills/ip-character-designer
cp -R 品牌IP与形象/pai-infinite-loop-ip ~/.grok/skills/pai-infinite-loop-ip
```
