# 品牌IP与形象

本会话用到的 IP / 头像 / 角色设计 skill。分类与 `设计和UI`、`购物` 并列。

## Skills

| 目录 | 用途 | 来源 |
| --- | --- | --- |
| `ip-as-logo/` | 极简圆角吉祥物方图，三色、从边角探出 | [s1dashu/ip-as-logo-skill](https://github.com/s1dashu/ip-as-logo-skill) MIT |
| `personal-ip-image-pack/` | 授权照片转可复用个人卡通 IP | [DoraRabbitYan/personal-ip-image-pack](https://github.com/DoraRabbitYan/personal-ip-image-pack) |
| `ip-character-designer/` | 动漫 IP 全案，S3 日系轻漫画等 10 种画风 | [Beatatata/ip-character-designer](https://github.com/Beatatata/ip-character-designer) MIT |
| `pai-infinite-loop-ip/` | Pai 品牌专用：无限循环 ♾️、永不相同、奶油底全身人设 | 本会话沉淀 |
| `ip_illustration_for_yourself/` | 萌粒风个人 IP 全套：锚点、插画、贴纸、表情、实拍融合 | [EverettFish/ip_illustration_for_yourself](https://github.com/EverettFish/ip_illustration_for_yourself) |
| `avatar-forge-skill/` | 可复用、风格锁定的人物/角色头像（5 套 Style Pack） | [SeasonXue/avatar-forge-skill](https://github.com/SeasonXue/avatar-forge-skill) MIT |
| `Punk-Skill/` | `punk-avatar` 头像 + `punk-cover` 封面 | [adrianpunk/Punk-Skill](https://github.com/adrianpunk/Punk-Skill) |

上游快照只含说明层。示例图、style pack 图、scripts 仍以上游仓库为准。

```bash
cp -R 品牌IP与形象/personal-ip-image-pack ~/.grok/skills/personal-ip-image-pack
cp -R 品牌IP与形象/ip-character-designer ~/.grok/skills/ip-character-designer
cp -R 品牌IP与形象/pai-infinite-loop-ip ~/.grok/skills/pai-infinite-loop-ip
cp -R 品牌IP与形象/ip_illustration_for_yourself ~/.grok/skills/ip_illustration_for_yourself
cp -R 品牌IP与形象/avatar-forge-skill ~/.grok/skills/avatar-forge-skill
cp -R 品牌IP与形象/Punk-Skill/skills/punk-avatar ~/.grok/skills/punk-avatar
cp -R 品牌IP与形象/Punk-Skill/skills/punk-cover ~/.grok/skills/punk-cover
```
