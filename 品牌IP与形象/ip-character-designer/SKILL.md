# 🎨 IP Character Designer

从一个模糊的角色概念出发，生成完整的 IP 角色设计全案，包括角色设定、视觉风格、表情系统、品牌物料清单，以及可直接投入即梦/Lovart 的生图提示词。

## 触发词
- "IP 设计" / "角色设计" / "做个形象"
- "设计吉祥物" / "品牌 IP"
- "表情包" / "帮我做套表情"
- "帮我做个卡通形象" / "设计一个角色"
- "mascot design" / "character design"

## 设计流程

当用户触发 IP 角色设计时，先走**Step 0 环境检测**，再进入设计流程。

### Step 0：环境检测 & 欢迎引导

首次使用时，用轻松的语气跟用户确认环境：

```
👋 欢迎使用塔塔的 IP 角色设计器！

开始之前，快速确认一下：

1️⃣ 你有安装即梦（Dreamina）CLI 吗？
   - ✅ 有 → 我可以直接帮你生图
   - ❌ 没有 → 没关系！我会给你完整的中文提示词，你复制到即梦网页版（jimeng.jianying.com）就能生图

2️⃣ 你有自己的 IP 角色参考图吗？
   - ✅ 有 → 发给我，我会基于你的角色生成各种场景和表情
   - ❌ 没有 → 也行！我们从零开始设计一个

准备好了就告诉我你想做什么 🎨
```

**检测规则**：
- 用户回答有CLI → 后续Step 6走即梦CLI生图
- 用户回答没有CLI → 追问：「要不要我帮你装？一行命令就搞定」
  - 用户说要装 → 引导执行 `npm install -g @anthropics/dreamina-cli`（或当前最新安装命令），装完后走CLI生图
  - 用户说不装 → 后续Step 6输出中文提示词，附带使用说明：「复制提示词 → 打开即梦 jimeng.jianying.com → 粘贴生图 → 如有参考图可上传到即梦的"参考图"功能」
- 用户发了参考图 → 自动存储路径，后续所有生图环节带参考图
- 如果是Cola内部调用（已知有即梦CLI或ListenHub），跳过Step 0直接进入Step 1

#### 即梦（Dreamina）调用

使用 `dreamina-cli` skill 生图。默认参数：
- `--model_version 4.5`（Seedream 4.5）
- `--resolution_type 2k`
- 比例按物料要求设置

```bash
# 角色主视觉
dreamina text2image \
  --prompt "{完整提示词}" \
  --ratio 3:4 \
  --model_version 4.5 \
  --resolution_type 2k \
  --poll 60

# 带参考图的角色延展
dreamina image2image \
  --image "{角色参考图路径}" \
  --prompt "{物料提示词}" \
  --ratio 1:1 \
  --model_version 4.5 \
  --resolution_type 2k \
  --poll 60
```

#### ListenHub 图片生成

```

```

### 塔塔默认模式（不指定风格时自动套用）

从塔塔大量实战出图中提炼的核心公式，默认生成**两个版本**：

**版本A · 白底扣图版**（默认）：
```
3D粘土渲染，柔软的哑光饰面，这个角色{具体动作姿态}，{表情细节：嘴角上扬/眼神有光/表情舒适恰意等}，{极简道具}。白色背景，方便扣图。超广角俯拍视角，夸张的透视比例关系，有冲击力的构图，富有感染力。高级质感，极简构图，元素不要杂乱。角色Q版比例，角色要完整不要裁切。玩具般的塑料质感，圆角，温暖柔和的光线。
```

**版本B · 场景背景版**：
```
3D粘土渲染，柔软的哑光饰面，这个角色{具体动作姿态}，{表情细节}，{极简道具}，{场景环境描述：地点+光线+氛围+色调}。超广角俯拍视角，夸张的透视比例关系，有冲击力的构图，富有感染力。高级质感，极简构图，元素不要杂乱。角色Q版比例，角色要完整不要裁切。玩具般的塑料质感，圆角，温暖柔和的光线。超高清，8K。
```

**⚠️ 参考图规则（关键）**：
- **有参考图时（image2image）**：提示词中**不要描述角色外貌**（发型、眼睛、服装等），角色信息完全交给参考图。提示词只写：动作、情绪、场景、道具、构图、质感。否则AI会过度参考文字而忽略参考图，导致角色走形。
- **无参考图时（text2image）**：提示词中需要完整描述角色外貌特征。

**多角色场景**：
- 支持同时传入多张参考图，生成多角色同框画面
- 即梦CLI用法：`--images "角色1路径,角色2路径"`（逗号分隔）
- 提示词中用"两个角色"/"三个角色"等自然语言描述互动关系
- 同样不描述各角色外貌，只写互动动作和场景

**两版差异只在背景**——白底版用于扣图做封面/贴纸/表情包，场景版用于小红书图文/社交传播。

**出图规则**：
- 用户未指定 → 默认出**白底版**
- 用户说"带背景"/"场景版" → 出**场景版**
- 用户说"两个版本都要" → A+B各出一张
- 可以同一个动作出两版（白底+场景），方便用户选择

**塔塔默认模式核心要素（缺一不可）**：
1. `3D粘土渲染，柔软的哑光饰面` — 风格基底
2. `超广角俯拍视角，夸张的透视比例关系` — 构图标配
3. `有冲击力的构图，富有感染力` — 情绪驱动构图
4. `高级质感，极简构图，元素不要杂乱` — 少即是多
5. `角色Q版比例，角色要完整不要裁切` — 硬规则
6. `玩具般的塑料质感，圆角，温暖柔和的光线` — 质感收尾

## 塔塔的独门技巧

从大量实战提示词中总结的关键手法：

### 1. 情绪先于动作
表情包不是画动作，是画情绪。先确定情绪（委屈、偷笑、崩溃），再设计能表达这个情绪的动作。

### 2. 配文驱动画面
先想好表情包的配文（"笑死"、"我裂开了"），再根据配文反推画面描述。配文是社交传播的核心。

### 3. 不裁切规则
表情包和头像：`角色正视镜头，聚焦头部但不要裁切角色头部要显示完全`。这是反复强调的硬规则。

### 4. 物料分层交付
按优先级分批出图，不要一次丢 50 张需求：
1. 先出角色主视觉（确认造型）
2. 再出三视图（锁定多角度）
3. 然后批量出表情（风格已锁定）
4. 最后出品牌延展物料

### 5. 风格变体实验
同一个角色可以尝试多种画风变体（如百变小TA的9宫格：粘土风、简笔画、3D 卡通、纸片风混搭），让一个 IP 拥有更丰富的视觉表达。

### 6. 产品化思维
每个 IP 都按"能开店卖周边"的标准设计——包装盒、贴纸、盲盒、笔记本封面、手提袋都要提前规划进物料清单。

### 7. 场景叙事
角色不能只站着。要给角色设计"在做什么"的场景：坐在电脑前、整理货架、抱着产品、站在吧台后面。场景赋予角色灵魂。

## 用途特化路径

### 路径 A：快速表情包

用户只想做一套表情包时的简化流程：

1. 确认角色（有参考图就直接用）
2. 选风格（默认 S2 Q版卡通）
3. 选表情数量（默认 9 张基础款）
4. 为每张表情生成：画面描述 + 配文
5. 批量调用即梦生图

### 路径 B：品牌 IP 全案

完整走 Step 1-6，交付物料包括：
- 角色设定表（Markdown 文档）
- 三视图 + 主视觉
- 9-24 张表情
- Logo 设计提示词
- 品牌规范图提示词
- 包装/周边提示词
- 官网 6 页结构提示词

### 路径 C：商单交付模板

为客户设计角色时的加强版流程：
1. 角色设定表（含中英文）
2. 多方案风格选择（出 2-3 个方向小样）
3. 确认后批量出全套物料
4. 所有物料清单带编号和比例标注
5. 交付提示词文档（客户可自行复用）
