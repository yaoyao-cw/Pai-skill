# 夏季泳装 × 男友视角自然抓拍 · summer-swimsuit-candid-pov

一个 Cherry Studio / Claude 的 Skill：输入人数、人物来源（原创 / 随机 / 垫图 / COS 角色），自动生成**一张**具有「私人相册感 × 夏季旅行感 × 亲密视角 × 自然抓拍感 × 真实摄影感」的**成年人物夏季泳装提示词**。

## 特性

- 单人 / 双人 / 多人（严格 **ONE IMAGE**：单图但可多人同框，禁止拼图 / 联系表 / 分镜 / 多窗口）
- 原创 / 随机人物；**人物垫图、多人物垫图、发型 / 服装 / 姿势 / 构图 / 场景 / 摄影风格垫图**（垫图只约束其承担的那一项职责）
- **Universal COS**：任意电影 / 游戏 / 动漫 / 漫画 / 电视剧 / 小说 / 特摄 / 虚拟角色，同作品多角色或跨作品联动
- 角色 DNA 自动解析 + 三级 COS 强度（Inspired / Recognizable Real-Life COS / Full COS）
- **Character-Inspired Swimwear Translation**：保留角色 DNA，而非简单换色比基尼
- 男友 / 伴侣 / 朋友 POV 亲密抓拍，面对镜头有熟悉感（familiar camera presence）
- 多人独立 Identity Anchor + Character Anchor，围绕单一核心事件形成自然反应链
- 摄影语言：35mm Film / 90s Compact / 2000s CCD / Disposable / Early Smartphone、28–40mm、真实皮肤、水元素、自然光、摄影不完美感

## 安全边界

主体 21–30 岁成年人；未成年 / 幼态角色自动转为成年 COS reinterpretation；严格单图；虚构摆拍。**只交付提示词，不直接生图。**

## 用法

把 `SKILL.md` 放入你的 Skill 目录（Cherry Studio 用户可直接放到 `Data/Skills/` 下），然后：

```
帮我做一张夏天泳池边的自然抓拍
帮我做一张 2B 的夏季泳装照
帮我做一张 2B 和雷电将军一起度假的泳装照
（上传人物垫图 + 海边民宿）
（上传多人物垫图 + 指定原作世界背景）
```
