# 麦田 · 发布流程

> 配合 [麦田](https://github.com/CzzzzzzJ/mdldm-maitian)（调度和数据）与 [麦田发布助手](https://github.com/CzzzzzzJ/mdldm-maitian-publisher)（各平台填写）使用。
> 这份是通用版。你的个人偏好（文风、账号名、引流链接、封面模板）写在自己的个人 skill 里，开头写「先读 maitian-publish，再按本文件覆盖」。

## 三者分工

| 谁 | 做什么 |
|---|---|
| 本 skill（AI 助手） | 看片、写各平台文案、确认封面、生成发布工程并校验、交给麦田 |
| 麦田发布助手（插件） | 打开各平台上传页，传视频和封面、填文案、设定时 |
| 麦田 | 什么时候跑、跑到哪、防重、等你点发布、到点取链接、每天采数据、飞书通知 |

## 流程（按序，不跳步）

```
① 看片 → ② 写发布素材 md → ③ 确认封面 → ④ 建发布工程 → ⑤ 生成 publish.json 并校验
→ ⑥ hub plan 进分发计划 → ⑦ hub run 填写 → ⑧ 你点国内平台的发布 → ⑨ 取链接、回填
```

### ① 看片

找到成片（路径、时长、分辨率）。有字幕或口播稿就以成片为准纠错：产品名、人名、转写错字一律改对。记下章节时间轴。

### ② 写发布素材 md

一期一个 md，章节名和加粗字段名必须按下面写，`make-publish` 靠它们取文案：

```markdown
# 系列名 · 第 N 期｜本期标题

> 序号：N
> 定时发布：2026-11-20 18:00          ← 没有定时就删掉这行
> 成品视频：/path/to/成片.mp4

## 三、B站
**标题：**
……
**简介：**
……（开头一段介绍 → 链接区 → 章节 → 结尾）
**标签：**
#账号名 #标签2 #标签3

## 四、小红书
**标题：**
……（≤20 字）
**正文：**
……
#账号名 #话题2 #话题3

## 五、抖音
**标题：**
……（≤30 字）
**正文：**
……
#账号名 #话题2（话题最多 5 个）

## 六、视频号
**短标题：**
……（6–16 字）
**描述：**
……
#账号名 #话题2

## 七、YouTube
**标题：**
……（≤100 字）
**简介：**
……（不能有 < >）
**标签：**
账号名, 标签2, 标签3

## 八、X
整节就是推文（中文按 2 字符计，超过 280 需要 Premium）
**长文：** https://x.com/compose/articles/edit/<id>   ← 可选：这期要「长文 + 视频帖引用长文」时加这一行，其余内容就是视频帖文案

## 九、Instagram       ← 可选
整节就是配文（≤2200 字，话题标签 ≤30 个，写在末尾；链接点不了，写「主页简介里的链接」）

## 十、知识站          ← 可选：接了自有站点才写
**系列：** 系列名
**免费 / VIP：** 免费
**标题：**
**简介：**
**详细介绍：**
```

各平台规则（实战总结）：

- **只在长文平台放链接**：B站、YouTube、X。链接带 `utm_source=<平台>&utm_medium=video&utm_campaign=<主题>-<序号>`，麦田靠 `utm_campaign` 把站点转化归到这一期。
- **小红书、抖音、视频号不引流**：不放链接、微信号、「去主页 / 评论区领 / 私信我」这类引导；不写海外模型和厂商名（Claude、ChatGPT、Gemini…），用 AI、Agent 代称。校验会拦。
- **Instagram**：网页上传的视频按 Reels 发，横屏保留原比例，用 16:9 封面；视频最长 20 分钟、文件最大 1GB，超了先转一版 `成片-ig.mp4` 放进工程目录（`make-publish` 会提醒并自动给 IG 用）。
- 每个平台的标签第一个放账号名（`make-publish --require <账号名>` 会检查）。
- 小红书写成「跟朋友讲这周干了啥」：为什么做、几个真实例子、踩过的坑；少 emoji、少清单。

### ③ 确认封面（门禁）

写完文案先给 2–3 套封面文案让用户选，确认前不出图。封面要求：主标题够大（手机缩略图一眼能读清），出两张：竖 3:4（小红书、抖音、视频号主页）、横 4:3（B站、抖音、视频号分享卡）；YouTube 的 16:9 由 4:3 左右补模糊背景生成：

```bash
ffmpeg -v error -y -i 封面/cover-4x3.png -filter_complex "[0]scale=1920:1080:force_original_aspect_ratio=increase,crop=1920:1080,boxblur=40:2,eq=brightness=-0.06[bg];[0]scale=-2:1080[fg];[bg][fg]overlay=(W-w)/2:0" -q:v 3 封面/cover-16x9.jpg
```

### ④ 建发布工程

```
<rootPath>/<系列>/<期>/
  成片.mp4            统一叫这个名字
  字幕.srt            可选
  发布素材.md         ② 的备份
  封面/cover-3x4.png  cover-4x3.png  cover-16x9.jpg
```

- 成片导出后先把响度标准化到 -16 LUFS（只重编码音频），并且**必须 faststart**（`-movflags +faststart`），否则小红书报「无视频流信息」。
- 拷到 NAS 时 `cp -X`；大文件报 `fcopyfile failed` 就用 `cat 源 > 目标`，拷完核对大小。

### ⑤ 生成 publish.json 并校验

```bash
node <发布助手>/tools/make-publish.mjs "<发布素材.md>" "<工程目录>" --require <账号名>
node <发布助手>/tools/validate.mjs "<工程目录>"
```

有 ❌ 就改 md 再生成，直到「✅ 校验通过」；⚠️ 逐条看一眼。某个平台这期不发，在 `publish.json` 里给它加 `"skip": "原因"`。

### ⑥ 进分发计划

```bash
node <麦田>/src/hub.mjs plan "<工程目录>"
```

麦田大屏上会出现这一期（「分发计划」），平台都是「计划中」。不手动 plan 也行：守护进程每 30 分钟扫一遍 `rootPath`，定时在未来的工程会自动进计划。

### ⑦ 开跑

```bash
node <麦田>/src/hub.mjs run "<工程目录>"     # 放后台跑
```

麦田先查登录、再分批上传（避免一次传太多互相抢带宽）、防重。X、YouTube、Instagram、自有站点回读一致后自动提交；B站、抖音、小红书、视频号**填好就停**，飞书通知你去点。

- **登录**：开跑前先查一遍要跑的平台，没登录的立刻飞书提醒，其他平台照跑；你扫完码 20 分钟内麦田自动补跑。守护进程在发布前一晚 20 点后也会查一遍。
- **自动提交卡住时**（页面已经填好，但麦田没点）：`hub submit <id> <instagram|youtube|x>` 单独提交一次。它会先查重，要求专用 Chrome 里恰好有一个填好的发帖页，然后存档截图、核对、点一次、记状态。不要自己另写脚本去点，避免发重。
- **Instagram 查重**：定时中的 Reels 不在主页列表里，麦田会去「定时内容」页（`instagram.com/scheduled_content/`）翻到定时那一周核对。
- **自有站点没有定时**：建课转码完就上线。想让会员抢先看就加 `--now`（`hub run <目录> --only zsz --now`），否则麦田会推迟到定时前 30 分钟再建课。

X 长文模式：先在 X 建好长文草稿（可用 `node <发布助手>/tools/article.mjs <笔记.md> <草稿标签页 id>` 把 Obsidian 笔记写进去），把草稿地址写进「八、X」的 `**长文：**` 行。麦田会在定时前 25 分钟启动长文脚本：先上传视频帖，到点发长文，再把长文链接贴进视频帖变成引用发出。需要日常 Chrome 里装着麦田发布助手。

### ⑧ 你点发布（国内四家）

点之前检查：能勾原创的都勾上（视频号「声明原创」、小红书「原创声明」、B站创作声明）；定时时间对不对。点完以后去作品管理页看一眼平台记录的定时——视频号偶尔会被改成别的时间，麦田取链接时也会比对并报警。

### ⑨ 取链接、回填

到点后守护进程自动取链接，写回 `发布记录.json` 和发布素材 md 的「已发布」行。手动：`hub sync <id>`。平台认不出（比如标题改过）就 `hub mark <id> <平台> published --url <链接>`。

## 安全红线

- 只操作你自己的账号；不做评论、点赞、私信、关注这类互动自动化。
- **同一条视频每个平台只上传一次**，失败了先去平台确认没发出去再重跑。
- **小红书只读页面、像人一样操作**：不在页面里直接调它的接口，低频。
- 国内四家最后的「发布」永远由人点。
