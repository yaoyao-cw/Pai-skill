# 中文完整母版提示词

## 〖主体〗

一位年轻亚洲男性创作者，黑色中分短发，黑框眼镜，穿纯黑色 T 恤和黑色机能马甲，始终保持同一人物、同一服装、同一发型和面部特征。

场景始终位于同一间复古暖色调的个人工作室 / 家庭办公室。人物坐在深棕色木质书桌前，桌面放有米白色复古机械键盘、鼠标、老式 CRT 电脑显示器、暖色台灯、透明文件盒等物件；背景有百叶窗、木质柜体、文件资料和暖色环境灯。

核心事件：人物坐在电脑前进行创作和演示，随着他的动作，真实工作空间逐渐被“电影后期制作能力”改写。镜头视角快速变化，桌面和设备发生视觉变形；人物用手指直接操控空气中的虚拟后期界面，曲线、参数面板、监视器窗口悬浮在真实空间中，形成现实拍摄与电影后期软件融合的效果。

所有变化都像发生在同一个真实空间里，不是普通硬切换场景，而是利用人物动作、电脑显示器、手势和镜头运动完成连续视觉转场。

## 〖风格〗

总时长约 11 秒，16:9 横屏。

真实电影摄影质感，略带复古 DV / 90 年代工作室气息，同时融合现代高端 VFX 视觉效果。整体采用暖棕色、琥珀色、奶油白、黑色为主色调。

使用超广角和鱼眼镜头语言，明显的广角透视畸变，人物靠近镜头时面部产生自然广角夸张。近距离手持摄影感，镜头具有轻微呼吸和惯性，不要完全稳定。

暖色钨丝灯照明，百叶窗投射自然光影，局部高光柔和，背景略暗。浅景深与广角深景深交替出现。

节奏快速、年轻、有创作者短视频感。镜头不断切换：正面鱼眼广角 → 超近距离自拍视角 → 电脑侧后方视角 → 高位俯拍 → 垂直顶拍 → 正面手指触碰镜头。

VFX 界面不是简单贴图，而是真正存在于三维空间中的半透明悬浮界面，有透视、景深、反射、遮挡关系。

## 〖时间线〗

### 〖0—1.2 秒〗

正面鱼眼超广角镜头。人物坐在木质书桌中央，双手放在米白色键盘附近，直视镜头。桌面因为鱼眼镜头形成明显弧形透视，左右环境向边缘拉伸。镜头快速向人物和桌面推进。

随后人物抬起双手，手中 / 身体周围快速出现摄影和创作设备：相机、摄像机、显示设备等从人物两侧展开，形成类似“多臂创作者”的视觉效果。设备运动具有真实重量感和运动模糊。

### 〖1.2—2.8 秒〗

人物与摄影设备形成夸张、多手臂、多工具的视觉构图。设备围绕人物呈扇形展开，但人物本体保持稳定。

利用人物抬手动作快速完成转场。镜头突然靠近人物。人物进入极近距离自拍式鱼眼镜头，脸部靠近镜头，黑框眼镜和面部产生自然广角透视，人物对镜头说话并做手势。

画面短暂形成双画面 / 分屏式视觉结构：一个角度从稍高位置观察人物，另一个角度是极近距离人物面部，两个画面保持同一空间和同一人物连续性。

### 〖2.8—4.5 秒〗

镜头从人物近景快速转向电脑侧后方。一台复古 CRT 显示器占据前景，人物坐在显示器后方操作键盘。

显示器边缘出现柔和发光描边，空间开始发生“后期制作”式变化。电脑屏幕附近生成透明的三维界面层，像玻璃面板一样从显示器中向外展开。

人物、桌面和背景保持真实摄影质感，只有数字界面具有轻微科技感。

### 〖4.5—6.5 秒〗

侧后方中广角镜头继续围绕人物运动。透明监视器窗口、画面预览框、后期参数窗口逐渐悬浮到人物与电脑之间。

虚拟界面具有真实三维空间关系：靠近镜头的界面轻微虚焦，人物后方界面更小，透明玻璃产生微弱反射。

镜头继续上升并绕过人物，自然衔接到高位俯拍。

### 〖6.5—8.5 秒〗

高位俯拍人物工作空间。人物坐在桌前操作电脑，暖色台灯照亮桌面一角，百叶窗投射柔和光影。

镜头继续升高并旋转，最终变成接近 90 度垂直顶拍。顶拍画面清楚看到：CRT 显示器、米白色键盘、鼠标、台灯、电话、桌面和人物双手。

镜头运动保持连续，像一台虚拟摄影机自由穿梭在房间中，不同焦段和不同机位自然衔接。

### 〖8.5—11 秒〗

快速切回人物正面近景。人物伸出食指直接触碰镜头前方空气。

手指接近镜头时，出现柔和的圆形波纹 / 透明能量圈，像触碰一个不存在的数字屏幕。

随着手指移动，多个专业后期制作 UI 界面从人物周围依次弹出：曲线调色窗口、参数控制面板、图像监视器、节点 / 调节窗口。

界面悬浮在人物前方和左右两侧，具有明显空间纵深，跟随镜头产生正确视差。人物用手指拖动其中一个控制点，曲线实时发生变化，其他参数窗口同步响应。

最后定格在：人物正面对着镜头，食指位于画面中心前景，多个半透明专业后期界面悬浮在他的周围，真实房间仍然清晰可辨，形成“现实空间就是后期工作台”的最终视觉。

## 〖BGM〗

快节奏现代电子音乐，约 120—135 BPM，短促电子鼓点 + 低频 Bass + 数字 Glitch 音效。

0 秒快速进入节奏；人物展开多种设备时出现第一次重拍；极近景切换配合短促 Whoosh；电脑产生透明界面时加入数字启动音；俯拍镜头变化跟随连续节拍；最后手指触碰空气时加入清晰 UI 点击声和低频冲击。

每次镜头视角变化、设备出现、UI 弹出都尽量踩音乐节拍。

不需要生成对白。

## 〖限制〗

- 人物全程必须是同一人，禁止脸型、眼镜、发型和服装发生变化。
- 房间、木桌、CRT 电脑、键盘等核心环境保持空间连续性。
- 忽略并禁止生成右上角任何平台水印、Logo 或模型标识。
- 不要主动生成视频中用于讲解的中文大字幕。
- 多手臂效果只允许出现在开头的创意特效阶段，不要导致人物永久畸形。
- 虚拟 UI 必须具有正确透视、遮挡和景深，禁止像二维贴纸一样固定在屏幕上。
- 手指不能畸形、不能增加手指，触碰虚拟界面时保持自然人体结构。
- CRT 显示器、键盘、桌面物体不能在镜头切换时随机变形或消失。
- 不要赛博朋克霓虹风，不要蓝紫色科技空间，始终保留暖色真实工作室摄影质感。
