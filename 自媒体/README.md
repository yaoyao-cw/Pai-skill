# 自媒体

内容生产、分发、账号运营相关 skill。

## Skills

| 目录 | 用途 | 来源 |
| --- | --- | --- |
| `Easel/` | OpenClaw 自媒体 skill 包（优先 `skills/openclaw`） | [ZJU-REAL/Easel](https://github.com/ZJU-REAL/Easel) |
| `native-subtitle-quote-image/` | 真实视频帧做成 3:4 社交字幕长图；原生不重绘、脚本不冒充 | [chengyi-ai/native-subtitle-quote-image](https://github.com/chengyi-ai/native-subtitle-quote-image) |

## 安装

把需要的子 skill 拷到 agent skills 路径，例如：

```bash
cp -R 自媒体/Easel/skills/openclaw/card-xiaohongshu ~/.grok/skills/card-xiaohongshu
cp -R 自媒体/native-subtitle-quote-image ~/.grok/skills/native-subtitle-quote-image
```
